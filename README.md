# Hestegrøavegen 64 – V6

Denne versjonen er laget som en mer ferdig og eksklusiv gjesteguide, samtidig som siden fortsatt er enkel å endre senere.

## Nytt i V6
- eget hero-bilde for sommer og vinter
- sesongstyrt innhold og bildebruk
- mer visuell og redaksjonell forside
- Hytta-siden har bildegalleri og tydelig emneoversikt
- WiFi, sengetøy, peis, kaffetrakter og badstue er enkle å finne
- full badstueinstruks med bilder av «i drift» og «avslått»
- Ski inn/ut har både standardrute og alternativ ved lite snø
- alternativet ved lite snø forklarer tydelig hvor man går til fots
- Gausta-siden har sesongtilpasset toppinnhold
- tekster er finpusset på norsk og engelsk
- designet er strammet opp med mykere kort, bedre spacing og mer raffinert bildebruk
- WiFi-passord er ikke publisert
